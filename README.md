# Study MBBS Abroad - Landing Page
A fully responsive landing page using Tailwind CSS, JavaScript, and PHP backend.

## Features
- Mobile-friendly design
- Form validation (JS & PHP)
- SEO optimized
- Performance tracking (Google Analytics, Facebook Pixel)
- AJAX form submission
- Email notification for admin

## Deployment
Live demo: [Netlify/Vercel Link]
GitHub: [Repo Link]
Backend: Hosted on PHP server

## Setup
1. Upload the `backend/` folder to a PHP-enabled server.
2. Deploy the frontend using Netlify/Vercel.
3. Update the form action URL in `index.html` to your backend server.
